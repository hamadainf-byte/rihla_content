# محتوى تطبيق رحلة التعلّم

## الهيكل
```
content/
  primary/    p1 … p5     (الابتدائي: الأولى إلى الخامسة)
  middle/     m1 … m4     (المتوسط: الأولى إلى الرابعة)
  secondary/  s1 … s3     (الثانوي: الأولى إلى الثالثة)
     └ s3/
        ├ math/      رياضيات
        │   ├ lessons/     دروس (PDF، أو videos.txt لروابط يوتيوب)
        │   ├ summaries/   ملخصات
        │   └ exams/       امتحانات وفروض وبكالوريا وتمارين
        ├ physics/   فيزياء
        ├ arabic/    عربية
        └ english/   إنجليزية
```

## تسمية الملفات (حروف لاتينية، بلا مسافات)
- `bac-2017.pdf` يظهر: بكالوريا 2017
- `bac-2017-solution.pdf` يظهر: بكالوريا 2017 التصحيح
- `devoir-t1-1.pdf` يظهر: فرض الفصل الأول 1
- `summary-1.pdf` يظهر: ملخص 1

## روابط الفيديو
ملف `lessons/videos.txt`، في كل سطر: `عنوان الدرس | رابط يوتيوب`

## عند إضافة محتوى جديد
1. ضع الملف في مجلده الصحيح.
2. شغّل `python build_catalog.py` فيُحدَّث `catalog.json`.
3. ارفع الملف الجديد و`catalog.json` إلى GitHub (Add file ثم Upload files).
